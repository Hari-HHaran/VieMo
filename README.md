# VieMo

A social film club: discover films through friends, keep a diary, curate collections, and decide together on Movie Night.

- `design-system/` holds tokens (`tokens.json`, compiled `tokens.css`), fonts, the React component bundle (`components/bundle.js` → `window.VieMo`), and the brand book (`README.md`, `navigation.md`, `accessibility.md`).
- `docs/plan.md` covers the product foundation, data model, stack, build sequence and external dependencies, with each part's status.

The app itself is not built yet; see the plan for what comes next.
