# EmptyState

Says honestly that there is nothing here yet and offers the most useful next step.

**Provide:** a `title` that states the situation, a `body` that explains why in one or two sentences, and one `action` (plus an optional `secondaryAction`).

- Never fill an empty place with sample films, fake friends or made-up numbers. "Popular with friends" with no friends shows this, not trending titles relabelled.
- Write the title as a plain fact ("Your feed is quiet", "No collections yet"), not a joke or an apology.
- Use `compact` inside a section; the full size for a whole tab.
