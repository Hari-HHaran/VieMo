# Icon

Lucide 0.460.0 outline icons (ISC licence) drawn at 24px on a 24 grid with a 1.75 stroke, coloured by `currentColor`.

**Provide:** `name` from the set below and a `size` (16, 18, 20 or 24). Pass `label` only when the icon stands alone and carries meaning; otherwise it is hidden from assistive tech.

- An icon never ships without a word next to it, except in an `iconOnly` Button (which has a label) and the Rating stars (which have `aria-label`).
- Active and selected states raise the stroke to 2.25 and change colour; they never rely on colour alone.
- Use `filled` only for a liked heart and filled rating stars.
- In the app, use `lucide-react` at the same version; the names match. Need an icon that is not here? Add it from Lucide; do not draw one.
